# Kompiuterio paruošimas darbui su JavaScript

### Įrankiai
- **Naršyklė**: Google Chrome, Mozilla Firefox arba kita moderni naršyklė su kūrėjo įrankiais (F12 arba Ctrl+Shift+I).
- **Kodo redaktorius**: Visual Studio Code (VS Code).
- **Node.js**: aplinka, leidžianti paleisti JavaScript kodą kompiuteryje be naršyklės.

### VS Code plėtiniai
- **Live Server**: leidžia paleisti lokalų serverį vienu paspaudimu (Go Live) ir automatiškai atnaujina puslapį išsaugojus failą.
- **Prettier - Code formatter**: automatinis kodo formatavimas (Shift+Alt+F).
