# 1. JavaScript įvadas

JavaScript yra dinaminė, interpretuojama programavimo kalba, skirta suteikti interaktyvumo ir funkcionalumo interneto svetainėms.

Dokumente naudojamas griežtasis režimas:
```js
"use strict";
```
Jis padeda aptikti klaidas ir neleidžia naudoti nedeklaruotų kintamųjų.
